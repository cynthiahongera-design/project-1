# Senior School ERP System

A comprehensive School Enterprise Resource Planning (ERP) system with full-featured management capabilities for students, teachers, classes, timetables, and report cards.

## 🚀 Features

- **User Authentication** - Role-based access (Admin, Teacher, Parent, Student)
- **Student Management** - CRUD operations, photo upload, performance tracking
- **Teacher Management** - Manage teacher profiles, subjects, qualifications
- **Class Management** - Class creation, stream management, subject allocation
- **Timetable Management** - Interactive timetable editor with drag-drop
- **Report Card System** - Generate detailed report cards with:
  - Individual student selection
  - Excel score sheet import
  - Auto-generated teacher/principal comments
  - Performance analytics with charts
  - Guardian signature section
  - Previous performance comparison
- **Event Calendar** - Manage school events and activities
- **School Branding** - Customize school logo, banner, and information
- **Data Management** - Import/Export data via Excel
- **Communications** - Email campaigns and WhatsApp broadcast

## 🛠️ Tech Stack

### Frontend
- HTML5/CSS3
- Tailwind CSS
- Chart.js
- FullCalendar
- SheetJS (Excel handling)
- Font Awesome

### Backend
- Node.js
- Express.js
- MongoDB
- JWT Authentication
- Multer (File upload)
- Nodemailer
- XLSX

## 📋 Prerequisites

- Node.js (v14 or higher)
- MongoDB (local or Atlas)
- npm or yarn
